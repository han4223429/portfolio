# HANYONG'S STUDIO — 디자인 가이드

**Document Version:** 1.0.0

**Updated:** 2026-10-06

**Reference:** 사용자 제공 STUDIO Interactive Editorial Web Experience PRD v1.0.0

## 방향

현재 포트폴리오의 종이색, 먹색, 코발트와 큰 이름 타이포를 유지한다. STUDIO PRD의 어두운 공간, 반응하는 3D 오브젝트, 편집형 작업 카드, 명확한 연락 동선을 개인 포트폴리오에 맞게 결합한다. 브랜드 이름은 김한용 / HANYONG'S STUDIO이며, 에이전시의 경력이나 전문성을 주장하지 않는다.

## 화면 순서

1. 짧고 건너뛸 수 있는 이름 인트로.
2. 종이색 첫 화면: 이름, 짧은 소개, 작업·연락 버튼. 옆의 어두운 3D 공간에서 기획·개발·콘텐츠 장면을 직접 선택한다.
3. 작업 전시: 실제 RESCUE JET, 올담 데이터 해커톤, 콘텐츠 제작을 동등한 세 카드로 보여준다. 각 카드는 같은 페이지의 상세 기록으로 이동한다.
4. 콘텐츠 갤러리: 기존 Instagram 38건을 6개씩 표시한다. 릴스 29·카드뉴스 9·Kalibrr 참여 9 필터와 원본 링크, 크게 보기 뷰어를 유지한다.
5. 기획·개발 상세: 실제 과정, 수상, 사진과 원본 기록 링크.
6. 소개와 작업 방식: 실제 인물 사진과 기획·개발·콘텐츠 세 축. 검증된 활동을 연도별로 정리한다.
7. 연락과 전체 보관 기록.

## 시각 규칙

- 페이지 바탕 `#ede8de`, 본문 `#263234`, 주요 포인트 `#3b58ad`.
- 3D 공간에만 깊은 먹색 `#101619`와 청록 `#87e7de`를 사용한다. 전체 화면을 검게 바꾸지 않는다.
- DM Sans / Noto Sans KR를 기본으로 하고 영어의 짧은 강조에 Georgia 이탤릭을 사용한다.
- 큰 제목, 작은 분류 태그, 1px 경계선과 넓은 여백으로 순서를 만든다. 설명은 짧은 한국어로 쓰고 작업 카드마다 연도·역할·결과를 구분한다.
- 확인된 인물 사진과 RESCUE JET 설계 이미지만 사용한다. 올담과 콘텐츠 카드의 타이포 그래픽은 정보 표현이며 실제 프로젝트 화면을 흉내 내지 않는다.

## 3D와 상호작용

- Three.js로 어두운 슬랩, 인스턴스 데이터 바, 점 파티클을 그린다. 이 오브젝트는 형태·흐름을 탐색하는 추상 인터랙션 스터디이며 실제 제품 모델로 소개하지 않는다.
- 기획·개발·콘텐츠 선택은 색, 방향, 파동과 해당 작업 링크를 함께 바꾼다.
- 데스크톱은 포인터에 관성 있게 반응하고, 모바일은 가로 드래그와 선택 버튼을 제공한다. 페이지의 세로 스크롤을 막지 않는다.
- 키보드 방향키와 회전·초기화 버튼으로도 공간을 조작한다.
- 장면이 화면을 벗어나거나 탭이 숨겨지면 렌더 루프를 멈춘다. 모바일의 바·파티클 수와 픽셀 비율을 낮춘다.
- 모션 감소·수동 모션 끄기에서는 자동 파동과 포인터 회전을 중지한다. 선택 버튼은 정지 장면을 즉시 갱신한다. WebGL 실패 시 정적 포스터와 작업 링크를 제공한다.
- 작업 카드에는 짧은 호버 강조만 적용한다. 게시물 갤러리는 읽는 동안 정지한다.

## 사실과 검증

제공 PRD의 AURA / VERVE / MONOLITH, 가상의 주소·수치·에이전시 선언은 사용하지 않는다. 확인되지 않은 LinkedIn·Twitter·채용 메뉴나 성과 지표는 추가하지 않는다. 인물·프로젝트·게시물·연락 내용은 기존 포트폴리오에서 확인된 내용을 유지한다.

배포 전 빌드, GitHub Pages 하위 경로, 데스크톱·390px·320px, 3D 선택·키보드·터치·모션 감소·WebGL 실패·메뉴·게시물 뷰어·원본 링크를 검증한다.
